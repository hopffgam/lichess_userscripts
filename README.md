# lichess_userscripts
Userscripts to enhance lichess in the web browser

To install a user script you first need to install a user script manager for your web browser as a browser extension. 

Which extension to install depends on the web browser that you are using, but versions of [Tempermonkey](https://www.tampermonkey.net) and/or [Violentmonkey](https://violentmonkey.github.io/) exist for the most common web browsers. 

Once the user script manager is in place, add a new script and paste the code from the file that you are interested in. The exact procedure will depend on the specific user script manager.
